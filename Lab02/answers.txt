Question 1: If you create a constructor method to build a DVD by title then create a constructor method to build a DVD by category. Does JAVA allow you to do this? 

Answer: No, Java does not allow this. Both the title and category parameters are of the String data type. In Java, method and constructor overloading is determined by 
the signature, which includes the parameter types and their order. Because both constructors would take exactly one String argument, their signatures would be 
identical: DigitalVideoDisc(String). The Java compiler cannot differentiate between the two based on the variable names alone.


Question 2: When should accessor methods be used? 


Answer: Based on Allen Holub's article "Why getter and setter methods are evil" , accessor methods should generally be avoided because they expose the internal 
structure of a class, which breaks encapsulation. Instead of using getters to pull data out of an object and manipulate it elsewhere, developers should follow the 
"Tell, Don't Ask" principle, where the class containing the data also contains the logic to operate on that data. Accessor methods should only be used when the sole 
purpose is data transfer, such as retrieving information specifically to display it on a user interface.
